# Noel Ortiz — Portfolio

Portfolio profesional de **Noel Ortiz**, Tech Lead y Desarrollador Full Stack.

Construido con React 19, TypeScript, Vite y Tailwind CSS. Incluye soporte multiidioma, modo claro/oscuro y una vista optimizada para impresión (CV).

## Tecnologías

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4
- Motion (animaciones)
- Lucide React (íconos)
- Firebase Hosting (despliegue)

## Desarrollo

```bash
npm install       # instalar dependencias
npm run dev       # servidor de desarrollo en http://localhost:3000
npm run build     # build de producción
npm run preview   # previsualizar el build
npm run lint      # chequeo de tipos con tsc
```

## Estructura

```
src/
├── components/     # layout, secciones y vista de impresión
├── constants/      # traducciones y tecnologías
├── hooks/          # idioma, tema, portapapeles
├── data.ts         # datos del portafolio
└── App.tsx
```
